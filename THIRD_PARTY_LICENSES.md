# Licences des composants tiers

> ⚠️ **Fichier généré automatiquement — ne pas modifier à la main.**
>
> Ce fichier est produit par [pip-licenses](https://github.com/raimon49/pip-licenses) (MIT) dans la CI GitHub Actions, à chaque build, à partir des dépendances Python réellement installées (y compris transitives). La CI échoue si une dépendance sous licence **GPL, LGPL ou AGPL** apparaît, conformément au règlement CADEV 2026.
>
> Commande utilisée :
>
> ```bash
> pip-licenses --from=mixed --format=markdown --with-urls --order=license > THIRD_PARTY_LICENSES.md
> python scripts/check_licenses.py   # échoue sur GPL / LGPL / AGPL
> ```
